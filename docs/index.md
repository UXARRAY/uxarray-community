# UXarray Community

A shared space between the [UXarray](https://uxarray.readthedocs.io) team and its user
community: demonstration notebooks from the team, notebooks users put together to ask
questions or report behavior, workshop and tutorial material, and anything else that comes
out of working together.

Browse everything in the **[Catalog](entries/index.md)**, organized by date.

Notebooks are shown with the outputs their authors committed. Many of them run only on HPC
systems where the data lives, so each entry describes its data and pins its own
environment if you want to run it yourself.

Want to add an entry or ask a question with a notebook? See the
[contributing guide](https://github.com/UXARRAY/uxarray-community/blob/main/CONTRIBUTING.md).
